# VLC Booster —— VLC 按键增强助手 (macOS)

给你的 VLC 增加三个顺手的功能:

| 操作 | 效果 |
| --- | --- |
| 长按 `→`(右箭头) | 以 3 倍速播放,松开立即恢复原来的速度 |
| 单击 `→` | 快进 5 秒 |
| 单击 `←` | 快退 5 秒 |
| 空格 / 点击播放画面 | 暂停 / 播放(VLC 自带,无需本程序) |

快进快退对视频和音频都有效。方向键只有在 VLC 处于最前台时才被接管,
在其他软件里打字、按方向键完全不受影响。

> 小科普:VLC 的官方插件接口感知不到"按住/松开"按键的时机,所以这个
> 工具是一个陪伴小程序——它在系统层面监听方向键,再通过 VLC 自带的遥控
> 接口控制播放。效果与插件相同。

## 第一次使用(共两步)

### 1. 双击启动

双击文件夹里的 **`VLC Booster.command`**。

- 如果系统提示"无法打开,因为来自身份不明的开发者":在文件上
  **右键 → 打开**,再点一次"打开"即可(只需一次)。
- 第一次运行会自动准备运行环境(需要联网,约 1~2 分钟),之后秒开。
- 如果 VLC 没开,它会自动帮你打开 VLC;如果 VLC 已经开着但连不上,
  按窗口提示在 VLC 里按 `Cmd + Q` 完全退出后再双击一次。

### 2. 授权"输入监控"

第一次运行时,系统会弹窗请求"输入监控"权限(它要监听方向键):

1. 在弹窗里点"打开系统设置"(或手动进入
   **系统设置 → 隐私与安全性 → 输入监控**);
2. 把列表里的 **终端 (Terminal)** 或 **iTerm** 打开;
3. 回到刚才的窗口,按提示重新运行(或再双击一次 `VLC Booster.command`)。

之后保持这个小窗口开着就行了,可以最小化不管它。

## 日常使用

每次想看视频时,双击 `VLC Booster.command`,它会自动把 VLC 拉起来。
想退出:在那个小窗口里按 `Ctrl + C`,或直接关掉窗口。

## 想改参数?

在"终端"里进入本文件夹后手动运行,例如改成 2.5 倍速、跳转 10 秒:

```bash
./.venv/bin/python3 vlc_booster.py --rate 2.5 --seek 10
```

| 参数 | 含义 | 默认值 |
| --- | --- | --- |
| `--rate` | 长按时的倍速 | 3 |
| `--seek` | 单击跳转的秒数 | 5 |
| `--hold` | 按住多少毫秒算长按 | 300 |
| `--port` / `--password` | VLC 遥控接口的端口 / 密码 | 8080 / vlcpassword |

## 常见问题

**Q:双击后提示连不上 VLC?**
A:说明 VLC 已经开着、但它的遥控接口没开。在 VLC 里按 `Cmd + Q`
完全退出,再双击一次 `VLC Booster.command` 即可。以后都让它来启动 VLC
就不会再有这个问题。
(手动开法:VLC 菜单 → 设置 → 左下角"全部" → 界面 → 主界面 → 勾选
"Web",密码设为 `vlcpassword`,重启 VLC。)

**Q:按键没反应?**
A:检查 系统设置 → 隐私与安全性 → 输入监控 里"终端"是否已打开;
改完权限后需要重新双击启动。

**Q:松开后速度没恢复?**
A:极少数情况下(比如程序在长按中被强制退出)会留在 3 倍速。在 VLC 菜单
"播放 → 播放速度"里调回正常即可,或重新运行本程序。

**Q:在 VLC 的搜索框里按方向键不动?**
A:这是已知的取舍——VLC 在前台时左右箭头会被本程序接管。需要输入时,
用鼠标点击移动光标即可。

**Q:想开机自动运行?**
A:可以把 `VLC Booster.command` 拖进 系统设置 → 通用 → 登录项。
